How This Was Built

🗂

Public Data Only

Every data point links to its original government source — NCES, TDOE, Census ACS, FutureEd. No proprietary or employer data.

📍

Economic Lens

Analysis framed by zip code, income level, district funding, and policy decisions. No demographic or racial framing.

🤖

AI-Generated Narrative

Each dashboard opens with an AI insight paragraph identifying the key finding and its policy implications.

⚡

One Day, One Dashboard

Pure HTML/CSS/JS — no build tools. Chart.js and D3.js via CDN. Deployable to GitHub Pages in under 60 seconds.

About This Project

This is a 10-day LinkedIn challenge built by Mahendra Aarumalla, a Data Scientist based in Memphis, TN. The goal: demonstrate that AI-powered data storytelling — applied to fully public government datasets — can surface insights that would take traditional analysts weeks to find.

The challenge started in Memphis neighborhoods and zoomed out to all 50 states, building one interactive dashboard per day using only data that any citizen can download for free. Every finding is sourced, every number is cited, and every dashboard is live.

Background: Python, SQL, PostgreSQL, FastAPI — and a genuine belief that public education data tells a story most people haven't read yet.
